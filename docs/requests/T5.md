# T5 integration requests (T3 / T6)

No contract changes are needed. T5 owns only the annotation implementation,
annotation files, its tests and maintainer skill; the following wiring belongs to
lower/CLI/verify owners.

- Load selected annotation lists with `load_annotations(path)` and perform T2
  syntax/symbol validation of `applies_when` in the declared lowering context.
  See `annotations/README.md` for the explicit source-backed predicate meanings;
  several are per-node, not model-wide flags. Do not default missing flags to
  false. In particular meta tensors deliberately skip NZ conversion, so loaded
  weight-layout intent must come from the upstream policy/config.
- Pass source trees keyed by `vllm` and `vllm_ascend` to
  `check_annotations(annotations, sources)`. Each SourceTree takes clone root,
  source repo label and full snapshot commit. It reads Git objects at that
  revision without imports. Append returned stale items to the existing Triage,
  stable-sort with other kinds, and exclude them from binding/application.
  Unresolved declarations raise ValueError and must fail the build.
- Use observed extract class swaps and patch bindings to choose an annotation
  per semantic IR node. Call `apply_annotations(ir, resolved, bindings=node_to_id,
  active_ids=selected_ids)` after selecting predicates through the shared TS DSL
  or an already-established fixed context. This is pure IR-in/IR-out, copies
  inputs, checks snapshot commits, and never evaluates expressions in Python.
  For interactive conditional mode changes, regenerate/reselect overlay metadata;
  AscendTag has no predicate field in the current wire format.
- The single `ascend.annotation_id` cannot represent multiple independent notes
  on one node. Explicitly bind the factory patch to the MoE block and the runner
  swap to its child; bind the attention patch to its group and projections to
  their nodes. Mutually exclusive NZ/custom-parallel lanes share a target.
  Preserve genuinely unresolved collisions as conditional triage rather than
  overwriting notes by file order.
- Annotations do not alter expressions. Account for the source-observed gate
  logits fp32 default, RoPE derived buffers, post-load expert transposition/NZ,
  and selected custom communications in rules/accounting or explicit exclusions.
  The drafts remain `reviewed_by: pending` as requested; human review policy
  remains an integration/publication responsibility.
- Maintainer wrappers forward arguments verbatim from `generator/`:
  scan→extract, triage→lower, verify→verify, golden_diff→golden, preview→site.
  Resolve is an explicit prerequisite; build composes stages. They assume only
  the T6 command names, no invented flags. The initial T0 CLI currently exposes
  only version, so real pipeline/preview smoke checks require T6's implementation.

The nine distinct layer replacement classes cover all twelve observed module
swaps; three endpoint implementations are covered too. Twenty-three draft notes
include exclusive mode lanes and four model-relevant patches. All hashes were
computed against the pinned clean source clones; no model weights or NPU work.

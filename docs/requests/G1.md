# G1 integration notes

F3's `web` hub has merged on main and G1-fix rebased onto it. The real
`inferatlas release --models qwen3-8b --devices A2` acceptance run passed,
including offline navigation through the generated hub and single export.
There are no pending requests for paths outside G1 ownership.

The generator passes the hub `INFERATLAS_DATA_DIR` (index.json, hardware.json,
hub.json) and `INFERATLAS_HUB_OUTPUT`; the exact interface and current validation
results are in `docs/progress/G1.md`. The hub must be `index.html` beside its
single exports because their All models links point to `./index.html`.

F3 constructs links in React: the exact href is present in rendered HTML, while
the raw file contains the embedded manifest and renderer. G1 verified the
rendered `href="./inferatlas-qwen3-8b-a2.html"` in offline Chromium without changing
web/**. Static prerendering, if later required, belongs to the web owner.

Release uses only sidecars written during that invocation. Standalone hub skips
invalid/unplaceable sidecars, supports valid catalog version pairs and prefers
the default filename for duplicate cells. Exit 2 means triage; exit 3 means a
build/verification failure, missing successful HTML, or zero linked exports.

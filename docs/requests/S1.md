## Frontend examples: copy into the unowned fixtures directory

S1's ownership list excludes `fixtures/**` even though the task requests examples in
`fixtures/arch/`. The examples are committed and schema-validated at:

- `generator/tests/fixtures_arch/qwen3-8b.json`
- `generator/tests/fixtures_arch/qwen3-30b-a3b.json`
- `generator/tests/fixtures_arch/synthetic-heterogeneous.json`

Please copy those files, with the same filenames, into `fixtures/arch/`. No transformation
is needed. `generator/tests/test_schema_contracts.py` already recognizes that location as
`arch.schema.json`. Real Qwen examples come from CPU/meta construction against the pinned
upstreams; the synthetic example has two dense layers followed by three MoE layers, MLA,
a sigmoid router, and one shared expert. `@inferatlas/contracts` exports `Arch` and the
`Arch*` component/module/stage/band/IO types.

## U1: consume the architecture bundle and independent numeric flag

`inferatlas build` now writes `arch.json` alongside `ir.json`, `view.json`, and `report.json`.
`site` copies all four artifacts for extracted cells, including cells with triage. Such
cells have `status: "triage"` and a non-null `data_path`; extraction failures have no link.
The `--include-blocked` site option remains accepted for compatibility but is unnecessary.
Exit 0 means structure was emitted; exit 3 means a hard failure. Source integrity and fixture
provenance checks remain hard errors.

Use `report.numeric_verified` for numeric panel verification. Structure and navigation must
remain available when it is false. Show `arch.notes` against their target ids (or globally
when target is null). Unknown I/O uses an empty inputs/outputs list, not an invented tensor.
`Module.source` is nullable for modules whose extraction has no source declaration. Component
parameter names can contain child paths: the list preserves the entire represented subtree.

The single-file staging directory also includes `arch.json`. The existing `web/vite.config.ts`
inline bundle filter currently only admits ir/view/report: please add `arch.json` to that
filter and extend the web bundle loader/type. These web changes are outside S1 ownership.

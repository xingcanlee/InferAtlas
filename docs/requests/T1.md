No schema or contract changes requested. EP baseline extraction works; combining EP
with an Ascend overlay currently reaches the upstream `get_mc2_group()` assertion
(`mc2 group is not initialized`). Supporting that combination needs an upstream CPU
MC2/HCCL mock with trustworthy constructor behavior. T1 does not fabricate it.

The real CPU patch scan has the same 130 entries as exp2 except the platform-selected
`vllm.models.deepseek_v4.cpu.model.FusedMoEFactory` replaces exp2's `.nvidia.model.`
entry (same Ascend origin). exp2 did not set `VLLM_TARGET_DEVICE=cpu`; the production
worker must. Integration should update the shared fixture if it is meant to represent
this CPU-selected patch scan. Tests assert the exact map with this one explicit change.

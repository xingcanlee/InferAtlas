# T2 integration requests

## Resolved: package dependencies and lockfile

T2-fix was authorized to update `pnpm-lock.yaml`. `@inferatlas/contracts` is now a
regular dependency of `@inferatlas/expr` because its public declarations re-export
contract types. Peggy and Vitest remain pinned dev dependencies. Frozen installs
pass, and the lockfile contains no registry URLs.

## T0 documentation and interface follow-up

The T2-fix review explicitly requested `format(src, mode, env?, precision = 4)` and
rounded human units. `packages/expr/README.md` documents these semantics and states
that error positions are not part of the cross-language contract; error codes are.
`docs/expr-dsl.md` remains T0-owned and still describes exact numeric formatting.
Please synchronize its API description when next updating the shared specification.

`packages/contracts/src/expr.ts` can add the optional fourth `precision?: number`
parameter to `ExprEvaluator.format` so consumers explicitly typed as `ExprEvaluator`
can select precision. The named `format` export and inferred `evaluator` export
already expose it, and both remain compatible with the existing interface.

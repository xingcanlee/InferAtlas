# T0 requests outside ownership

- Integration owner: add and commit `generator/uv.lock` and `pnpm-lock.yaml`, and remove
  `.npmrc`'s `lockfile=false` once those paths are authorized. T0 owns the listed manifests
  but not these lockfiles. uv creates a local lock during setup/tests; T0 removes it before
  committing. Direct JS dependencies are pinned, Python dependencies are constrained;
  transitive resolution across fresh installations is not frozen until the locks land.
- A root `tsconfig.json`/`tsconfig.base.json` was not among T0's enumerated owned root files.
  The shared strict TypeScript 5 base is therefore `packages/contracts/tsconfig.base.json`,
  with all skeletons extending it. No root tsconfig is necessary unless integration prefers it.

No changes were made to upstream experiments, existing design/dev-plan documents, rules,
annotations, workflows, or implementation directories beyond the explicitly requested stubs.

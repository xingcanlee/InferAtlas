# U1 → S1 (arch.json contract) requests / interpretations

The UI was built against hand-written fixtures (`fixtures/arch-ui/`) following
`docs/arch-contract.md`. Where the contract left room, U1 assumed the following; please confirm
or tell U1 what the emitter does instead (the UI adapts in `web/src/lib/arch.ts`).

1. **`residual_add` sublayers have `component: null`** (the Component union has no residual
   kind) and `module: null`. If the emitter omits residual adds entirely, the UI infers ⊕ after
   each mixer/ffn from `block.residual` — both work.
2. **Periodic patterns = consecutive bands sharing the same `pattern` label.** Qwen3-Next is 24
   bands (`[0,2]` linear, `[3,3]` full, …) all with `pattern: "3 × linear attention + 1 × full
   attention"`; the UI folds them into one `(3 + 1) × 12` group when the run is periodic.
3. **`notes[].target`** is a stage id (`"lm_head"`, `"mtp"`, `"layers"`), a band id, or
   `"<band id>/<sublayer id>"` for a sublayer. A shared "component id" format would be welcome.
4. **Band blocks carry the module path of the band's first layer** (`model.layers.3.mlp`); the
   UI rewrites `layers.<first>` to the selected layer.
5. Component extras the UI reads when present: attention `extras.output_gate` (gated attention),
   `extras.kind == "gated_deltanet"` with `num_v_heads`, `conv_kernel`; MLA `q_lora_rank`,
   `kv_lora_rank`, `qk_rope_head_dim`; `rope.scaling.partial_rotary_factor` / `factor` (YaRN).
   MoE router groups as `router.groups = {n_group, topk_group}`.
6. Shapes are global with `tp` as a symbol (default 1). If arch.json shapes become rank-local,
   please keep `tp` in `symbols` so the UI can still show/edit it.
7. `index.json`: structure-only cells (arch.json without ir.json) should have a `data_path`; the
   UI opens them on the Architecture tab and explains that the graph tab needs `ir.json`.

## How to run

```sh
pnpm install --frozen-lockfile --registry=https://registry.npmmirror.com
just schemas
uv run --project generator python generator/scripts/build_catalog_arch.py
uv run --project generator python generator/scripts/build_arch_fixtures.py
uv run --project generator inferatlas site --build-root .cache/S1-builds --data-dir .release-data
pnpm exec biome format --write --files-max-size=10000000 .release-data
just lint
just test
```

The scripts use the shared experiment interpreter and read-only upstream source checkouts, or INFERATLAS_PY / INFERATLAS_SRC overrides. Cache misses perform isolated offline CPU/meta construction; they never fetch weights. .release-data contains the site-ready index, hardware, and 32 model bundles. Extraction caches and intermediate build directories remain under ignored .cache/.

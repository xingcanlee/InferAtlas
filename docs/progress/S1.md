# S1-fix3 progress

## Done

Rebased task/S1 onto main and implemented the binding architecture contract v1.3. Changes are confined to generator code/tests, architecture rules, generated architecture fixtures/goldens, release data, and this progress report. No web/ or packages/arch-ui/ sources changed.

- Repeating regions receive one label per complete structural period, shared by their bands. Prefix/tail regions and homogeneous stacks remain unlabelled. Signatures include FFN routing, RoPE, and attention extras. DeepSeek-V4, gpt-oss, Qwen3-Next, and Llama-4 expose their actual repeated regions.
- Stage arrays preserve dataflow: DeepSeek-V4 hc_head_op is a spine other stage between the decoder stack and final norm. Vision adapters/projectors precede the language stack. Only aside stages are moved to the end.
- mHC operations retain their generic component, class/source/status, role other, and four band-relative ids. Their residual_streams tensors have shape [T, HC, H]; hc_head_op consumes these streams and emits [T, H].
- Hash routing is detected from the observed tid2eid parameter table, so DeepSeek-V4 layers 0–2 emit router.scoring hash.
- Attention variants describe head sharing or linear mixing. DeepSeek-V4 emits MQA with one KV head; sparse MLA remains MLA. Locality/compression/indexing and output projection metadata live in extras, including sliding_window on compressed layers, o_lora_rank, o_groups, and chunk_size.
- Internal tensors use the canonical v1.3 names. MoE expert rows account for routing/EP, shared experts expose shared_output, and linear mixers expose packed projections, convolution output, and recurrent state. Boundary outputs remain separate.
- Regenerated four Qwen goldens and both copies of the three architecture fixtures. Fresh CPU/meta extraction ran for all 32 model/device cells after expanding the attribute whitelist; final bundles and .release-data were rebuilt from those fresh facts.
- Reviewed docs/requests/S1.md: its outstanding requests concern UI consumers; no additional generator-side request remains.

## How to run

```sh
pnpm install --frozen-lockfile --registry=https://registry.npmmirror.com
# For a fresh extraction, remove the ignored .cache/S1 extraction directory first.
uv run --project generator python generator/scripts/build_catalog_arch.py
uv run --project generator python generator/scripts/build_arch_fixtures.py
uv run --project generator inferatlas site --build-root .cache/S1-builds --data-dir .release-data
pnpm exec biome format --write --files-max-size=10000000 .release-data
just lint
just test
```

The scripts use the experiment's shared CPU interpreter and read-only pinned upstream clones; INFERATLAS_PY and INFERATLAS_SRC can override their locations. Extraction cache keys hash the extractor implementation. Release data contains index/hardware metadata and all 32 bundles. No cache or intermediate build output is committed.

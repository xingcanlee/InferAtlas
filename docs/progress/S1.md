## How to run

```sh
uv run --project generator python generator/scripts/build_catalog_arch.py
uv run --project generator python generator/scripts/build_arch_fixtures.py
just schemas
uv run --project generator inferatlas site --build-root .cache/S1-builds --data-dir .release-data
pnpm exec biome format --write --files-max-size=10000000 .release-data
just lint
just test
```

The matrix helper validates cached snapshot/config/TP identity and uses fresh isolated CPU extraction on a cache miss. It builds the main-verified version pair at TP=1; existing extraction tests additionally cover TP/EP and deterministic worker bytes. The experiment interpreter and read-only source clones are found through the shared main checkout, or INFERATLAS_PY/INFERATLAS_SRC. Network mirrors are configured by just; extraction itself uses offline configs.

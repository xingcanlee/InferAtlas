# U4 — mobile / tablet, structure coverage on home, v1.4 UI follow-ups

Branch `task/U4` (from main incl. "Contract decisions v1.4"). UI only: `web/**`,
`packages/arch-ui/**`, `docs/progress/U4.md`. Generator / schemas / contracts untouched: every
v1.4 field (`IndexCell.coverage`, top-level `inputs`, `hc_expand` stage, class-level notes) is
read defensively and the UI degrades gracefully without it (current release data has none).

## 1. Mobile and tablet
Breakpoints: below `lg` (1024px) the architecture page switches to its touch layout; below `md`
(768px) the home matrix becomes cards and the nav collapses into a menu. Layout is chosen with
`useMediaQuery` (`web/src/lib/responsive.ts`, `useSyncExternalStore`, read before first paint,
so there is no layout shift); jsdom without `matchMedia` gets the desktop layout.

- **Shell**: `viewport-fit=cover`; `#root` uses `100dvh`; safe-area padding (`safe-px` /
  `safe-pl` utilities, `env(safe-area-inset-*)`) on header, toolbars, sheet and zoom controls.
  Phones: nav (Matrix / Diff, or "All models" in exports) in a shadcn `DropdownMenu`
  (`components/ui/dropdown-menu.tsx`); theme/menu/search buttons 40px.
- **Home**: phones get one card per model (name, HF id, one row per version, 40px cell links),
  family chips wrap (spaced toggle group), device switch and filter are 40px (16px input text, no
  iOS focus zoom). Tablets keep the table with 40px controls.
- **Model header**: back chevron instead of the breadcrumb, truncated title, icon tabs (with
  accessible names) on phones; 40px tabs below `lg`.
- **Architecture page (< 1024px)**: compact toolbar (40px layer stepper, "/ N", Details button,
  ⋯ menu with Internals / Fit / 100%), current band as a one-line button that opens the sheet.
  `FitBox` gained zoom: `zoom="fit"` fits the **width** on touch (desktop keeps fit-both with the
  0.9 floor), numbers are explicit zoom; native scrolling pans (drag with momentum),
  **two-finger pinch** and Ctrl/⌘ + wheel zoom around the gesture's focal point (non-passive
  listeners; `touch-action: pan-x pan-y` so the page never zooms). Floating thumb-reach
  − / Fit % / + buttons (40px). The detail panel is a shadcn **bottom `Sheet`**
  (`components/ui/sheet.tsx`, Radix Dialog): it opens on a figure tap, layer step or deep link,
  has its own Overview / ‹ › / close row, scrolls independently and keeps the selection when
  closed. Shape values are readable by tap (sheet lists symbolic = numeric; `ShapeLabel`
  click-pins). Sheet text ≥ 10.5px (panel badges bumped to `md`, triage-kind chip 11px).
- **Graph & analysis on phones (< 768px)**: a clear note with "Architecture" and "Open anyway";
  tablets and landscape phones get the workspace, which never overflows the page.
- Desktop is unchanged (same toolbar, side panel, fit floor); `ArchitectureView` is keyed by
  cell so per-model UI state (sheet, zoom, encoder) resets on model change.

## 2. Home: structure coverage
`lib/coverage.ts` + `components/CoverageBadge.tsx`. Cells lead with structure coverage from
`IndexCell.coverage` when present (`structure ✓ · 4/4 ruled`, or `10/12 ruled · 2 generic`, plus
`⚠ n` warnings), else a neutral `structure` badge; numeric/annotation verification is a subtle
secondary mark (`verified` / `unverified · N`, explanation in the title). No more
`triage · N` badges on home or the model header. Counts above the matrix: with structure /
numerically verified / missing. Version columns with no built cell on the device are hidden
(`v0.32.0` today). `archCoverage(arch)` derives the same numbers from an `arch.json`.

## 3. Review follow-ups
- **Class-level notes (v1.4 §2)**: `noteIndex` copies notes of kinds `unknown_layer_class`,
  `unannotated_override`, `conditional_override` (and the plain "Generic component" info note)
  to every instance of the target's class in the model; other kinds (e.g. `golden_diff`) stay on
  their target. Figure badges and panels use `subNotes` / `notesAt` — DeepSeek-V4's
  `mhc_pre_ffn` / `mhc_post_ffn` now carry ⚠ in every band.
- **Edge labels vs badges**: `FlowArrow`/`TensorEdge` take `labelSide`; spine edges into a
  badged node put the tensor label left of the wire, encoder-column edges into a badged node
  are longer — Llama-4's `hidden_states [P, 1408]` no longer overlaps G/⚠.
- **normalizeArch records patches**: deprecated variants, missing internals / placement / flags /
  notes are listed (`normalizePatches`), added as a model-level info note
  (`triage_kind: "ui_normalised"`, "Normalised for display …") and `console.warn`ed in dev.
  Real release data needs no patch.
- **Vision input terminal**: uses v1.4 `inputs` (first input other than the primary) when
  present, else the first encoder stage input, else a muted `image (not in arch.json)` pill
  (`FigureTerminal` `muted` / `hint`).
- **`hc_expand`**: rendered as a spine stage in array order with its `residual_streams` edge;
  `hc_expand` / `hc_head_op` read "mHC expand (→ HC streams)" / "mHC merge (HC streams →)".
- **release.spec**: every `ok`/`triage` cell must have a `data_path` and be a link on home.

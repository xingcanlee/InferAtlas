# T1 — resolve + extract

## Done

- Implemented catalog loading/validation, config hash checking, deterministic local
  `config.json` and `Snapshot` output. No HF calls or model weights.
- Resolved compatible versions from the pairing file **at the selected Ascend
  revision**. Existing read-only clones are reused; missing revisions use an isolated
  shallow cache (`git fetch --depth 1 <remote> <commit>`). Annotated and lightweight
  tags are tested with local remotes. Dirty checkouts are rejected.
- Exposed `inferatlas.resolve.resolve(model, version, device, out_path)` and
  `inferatlas.extract.extract(snapshot, model, tp, ep, device, out_path)` for T6.
  `get_model`, `load_catalog`, `write_config`, and checkout helpers are also public.
- Implemented an external `python -I` worker with an offline local config, forced CPU
  platform, real one-rank gloo initialization under `set_current_vllm_config`, meta
  construction under `set_default_torch_dtype`, and the verified `_ShimTP`.
  EP also shims this commit's `vllm.distributed.parallel_state._EP` coordinator.
- Emitted sorted modules/direct parameters, JSON-safe whitelisted observed attributes,
  quant-method class, layer types, version-only environment, and source provenance.
  `inspect.getsourcelines` plus AST locates declaration lines after decorators.
  External `torch.nn.ModuleList` sources are null; tied parameters are emitted once.
- Reused upstream Ascend conftest with exactly the verified two side-effect blocks
  removed; applied both patch phases and CustomOp registration explicitly. The scan
  guards lazy `getattr` and checks `types.CodeType`. Overlay builds preserve the
  baseline class/source and record each observed replacement separately.
- Validated worker responses with pydantic `Extract` before atomic output publication.
  Failed workers, invalid responses, or timeouts preserve any previous output.
- Generated baseline Qwen3-8B and Qwen3-30B-A3B at TP 1/2/4/8; A2 overlays at TP 1/4;
  baseline MoE EP at TP 4; and baseline DeepSeek-V3. Outputs are under `.cache/extract/`.
  Committed a real 16-module, layer-zero TP4/A2 sample at
  `generator/tests/fixtures_t1/extract-qwen3-moe-layer0.json` (about 38 KB).

## Decisions

- A single overlay worker constructs baseline and Ascend models separately, which
  makes baseline provenance independent of replacement class inheritance. It clears
  upstream `_ROPE_DICT` between builds: cached baseline rotary instances otherwise
  bypass CustomOp registration and hide two real swaps. No model/kernel code is patched.
- Source declarations are inspected once per class per build, avoiding repeated AST
  parsing across identical decoder layers.
- `python -I` ignores PYTHONPATH. The host still sets it as specified; the standalone
  worker explicitly adds the commit-checked upstream roots to `sys.path`.
- File-based gloo rendezvous avoids fixed TCP ports and supports concurrent workers.
- Config/model identity mismatches fail before extraction. `CatalogModel` arguments
  let callers use an explicitly loaded alternate catalog while preserving its hash.
- Main pairing files are authoritative over stale catalog display refs. No checkout
  changes are made to the shared source clones.

## Not done / limitations / deviations

- **EP + Ascend overlay is not supported by these upstream CPU mocks.** A real
  attempt fails at `AscendMoERunner -> get_mc2_group()` with
  `AssertionError: mc2 group is not initialized`. MC2 dispatch constructors also need
  an HCCL backend; none is fabricated. Baseline EP extraction and expert shapes work.
  Coordinator rank metadata is shimmed; underlying process groups remain real size one,
  so attributes read directly from a process group can still report one.
- The patch set differs from exp2 in exactly one symbol: CPU-selected
  `vllm.models.deepseek_v4.cpu.model.FusedMoEFactory` replaces its `.nvidia.model.`
  counterpart, with the same Ascend origin. exp2 did not select the CPU platform.
  Tests check the exact remaining map and this explicit platform substitution.
- A2 is verified. A3/A5/310P are accepted profile selections but are not claimed tested.
  Attention remains the CPU backend; quantized models, forward execution, real
  collectives, device memory layouts, and NPU behavior were not verified.
- Real release downloads were not exercised; release pairing, tag peeling, shallow
  fetch, cache reuse, and interrupted-fetch recovery were tested with local Git remotes.
- No schema changes. T1 stays based on the original T0 commit; integration must carry
  the T0 catalog fix before publishing. The normal integration tests follow whatever
  catalog is checked out, so pre-rebase runs also exercise the original dense config.
- Pytest marker registration and lockfile ownership are requested in
  `docs/requests/T1.md`; neither unowned file is modified here.

## How to run

From the repository root (Python 3.12):

```bash
UV_INDEX_URL=https://mirrors.aliyun.com/pypi/simple/ uv sync --project generator
uv run --no-sync --project generator pytest generator/tests -q \
  -o 'markers=extract: real CPU/meta extraction using the external environment'
uv run --no-sync --project generator ruff check \
  generator/inferatlas/resolve generator/inferatlas/extract \
  generator/tests/test_resolve.py generator/tests/test_extract*.py
uv run --no-sync --project generator ruff format --check \
  generator/inferatlas/resolve generator/inferatlas/extract \
  generator/tests/test_resolve.py generator/tests/test_extract*.py
```

Use `-m 'not extract'` for the fast suite. Real extraction tests are marked `extract`
and skip automatically if the external CPU interpreter or upstream sources are missing.
Defaults discover the main checkout's experiment environment even from a Git worktree.
Override with absolute `INFERATLAS_PY` (external venv interpreter) and `INFERATLAS_SRC`
(directory containing `vllm/` and `vllm-ascend/`) when needed.

```bash
uv run --no-sync --project generator python - <<'PY'
from inferatlas.resolve import resolve
from inferatlas.extract import extract

snapshot = resolve("qwen3-30b-a3b", out_path=".cache/resolve/moe/snapshot.json")
extract(snapshot, "qwen3-30b-a3b", 4, False, "A2",
        ".cache/extract/qwen3-30b-a3b/tp4-A2.json")
PY
```

The committed source contracts and shared fixtures remain unchanged. Only owned
implementation/tests, the required progress/request documents, and ignored local
cache/environment artifacts were written.

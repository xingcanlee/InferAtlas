# T1 — resolve + extract, review fixes

## Done

- Resolve pinned offline model configs and immutable upstream pairs using the
  pairing file at the selected Ascend revision. Reuse read-only local clones;
  shallow-fetch missing revisions into an isolated cache. Reject dirty checkouts.
- Expose `inferatlas.resolve.resolve(model, version, device, out_path)` and
  `inferatlas.extract.extract(snapshot, model, tp, ep, device, out_path)` for T6.
- Run CPU/meta construction in an external `python -I` worker. Use real one-rank
  gloo groups and construction-time TP/EP rank shims; no weights or HF calls.
- Emit sorted modules and direct parameters, JSON-safe observed attributes, layer
  types, and inspected source declaration lines. Deduplicate tied parameters.
- Preserve **all baseline attrs**, classes, sources, and parameters when adding
  Ascend overrides. This includes embedding/lm_head dimensions and baseline
  quant-method identities. Refreshed the owned layer-zero fixture accordingly.
- Clear inherited `VLLM_*` variables before forcing CPU and disabling plugins.
  Publish validated output atomically, setting `0o666 & ~umask` before replacement.
- Build the baseline first, destroy its distributed groups, apply both Ascend
  patch phases and CustomOp registration, then initialize fresh distributed
  groups. Thus the Ascend build follows exp3's patch-before-distributed-init order.
- Call `init_ascend_model_parallel` with a one-rank copy of ParallelConfig, then
  shim MC2 rank metadata to TP just as for TP/EP. MC2 groups now exist.
- Integration tests write configs, snapshots, and extracts to pytest temporary
  directories. Register `extract` in owned `generator/tests/conftest.py`, so
  `--strict-markers` works without editing T0's pyproject.
- Test QKV partition sizes and KV head counts at TP 1/2/4/8, including MoE TP8 KV
  replication. Compare the exact layer-zero baseline/Ascend class mapping against
  exp3, and compare every module's attrs against a separate baseline extraction.
- Remove the redundant `.cache/extract/qwen3-8b-corrected/` directory. Regenerate
  supported outputs explicitly under `.cache/extract/`, independently of tests.

## Decisions

- Keep baseline `attrs` authoritative. Ascend-specific attrs can describe useful
  implementation differences, but require a separate `ExtractOverride.attrs`
  contract field; requested in `docs/requests/T1.md`, with no schema edits here.
- Keep baseline and Ascend builds in one worker, recreating process groups between
  them. Clear `_ROPE_DICT` so baseline cached instances cannot hide rotary swaps.
- MC2 uses a real one-rank gloo group with rank metadata shims. Do not fabricate
  NPU process-group backends or bypass communication constructors.
- Source declarations are inspected once per class per build. File rendezvous
  avoids TCP port conflicts. Validate worker identity/config before publication.
- Current main's catalog is authoritative, including Qwen3-8B's 36 layers and
  intermediate size 12288. Cache regeneration is a separate, explicit operation.

## Not done / limitations / deviations from contracts

- **EP + Ascend overlay remains unsupported on these CPU mocks.** After MC2 is
  initialized successfully, `AscendMoERunner -> setup_moe_comm_method ->
  AlltoAllCommImpl -> TokenDispatcherWithAll2AllV.__init__` calls
  `self.ep_group._get_backend(torch.device("npu"))` in
  `vllm_ascend/ops/fused_moe/token_dispatcher.py:499` and raises
  `RuntimeError: No backend type associated with device type npu`. The underlying
  process group is gloo. This is no longer a missing-MC2 initialization problem.
  A regression test asserts this cause and preservation of the previous output.
- CPU selection replaces exp2's
  `vllm.models.deepseek_v4.nvidia.model.FusedMoEFactory` patch entry with its
  `.cpu.model.` counterpart, with the same Ascend origin; the other entries match.
- Only A2 is verified. Attention remains the CPU backend. Quantized models,
  forwards, real collectives, device layouts, and NPU behavior are unverified.
  Underlying process groups retain size one, despite shimmed coordinator metadata.
- Release downloads were not exercised; local Git remotes cover tags, shallow
  fetches, cache reuse, and interrupted fetches.
- No contract changes. Shared pyproject, lockfile, justfile, and shared fixtures
  were not edited. Integration requests are in `docs/requests/T1.md`.

## How to run

From the repository root (Python 3.12):

```bash
UV_INDEX_URL=https://mirrors.aliyun.com/pypi/simple/ uv sync --project generator
uv run --no-sync --project generator pytest generator/tests -q --strict-markers
uv run --no-sync --project generator ruff check \
  generator/inferatlas/resolve generator/inferatlas/extract \
  generator/tests/test_resolve.py generator/tests/test_extract*.py generator/tests/conftest.py
uv run --no-sync --project generator ruff format --check \
  generator/inferatlas/resolve generator/inferatlas/extract \
  generator/tests/test_resolve.py generator/tests/test_extract*.py generator/tests/conftest.py
```

Use `-m 'not extract'` for fast tests. Real CPU/meta tests skip if the external
interpreter or sources are absent. Worktrees discover the main checkout's experiment
venv and sources. Override using absolute `INFERATLAS_PY` and `INFERATLAS_SRC` paths.
Tests never regenerate `.cache/extract/`.

Explicit cache regeneration command (proposed body of `just extract-all`):

```bash
uv run --no-sync --project generator python - <<'PY'
import os
from pathlib import Path
from inferatlas.resolve import resolve
from inferatlas.extract import extract

root = Path(os.environ.get('INFERATLAS_EXTRACT_OUT', '.cache/extract'))
for model in ('qwen3-8b', 'qwen3-30b-a3b', 'deepseek-v3'):
    snapshot = resolve(model, out_path=root / model / 'snapshot.json')
    cases = [(1, False, None)] if model == 'deepseek-v3' else [
        *((tp, False, None) for tp in (1, 2, 4, 8)),
        *((tp, False, 'A2') for tp in (1, 4)),
    ]
    if model == 'qwen3-30b-a3b':
        cases.append((4, True, None))
    for tp, ep, device in cases:
        name = f'tp{tp}' + ('-ep' if ep else '') + (f'-{device}' if device else '')
        path = root / model / f'{name}.json'
        extract(snapshot, model, tp, ep, device, path)
        print(path, flush=True)
PY
```

This writes 14 extracts plus their configs/snapshots. Set `INFERATLAS_EXTRACT_OUT`
to redirect the whole regeneration. EP+A2 is intentionally excluded because its
constructor requires an NPU backend. The justfile recipe is requested, not edited.

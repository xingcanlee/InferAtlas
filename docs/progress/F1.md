# F1 — frontend (web/)

## Done

- **Stack** as specified: Vite 8 + React 19 + TS strict, Tailwind v4 (`@tailwindcss/vite`), shadcn/ui
  components (Radix; shadows stripped), TanStack Router (hash history, zod search schemas, route
  loaders), Zustand (theme/search/hover only), @xyflow/react with custom node types and a custom
  orthogonal edge that draws the `view.json` polyline (no layout engine in the browser), shadcn
  Charts (Recharts), vite-plugin-singlefile, Vitest + Testing Library, Playwright. Fonts are
  self-hosted Inter / JetBrains Mono (`@fontsource`, latin subsets).
- **Expressions**: `src/lib/expr.ts` wraps `@inferatlas/expr` (T2) `compile()` closures with a
  per-formula cache. The temporary fallback evaluator was deleted after T2 merged.
  `web build`/`test` first build `@inferatlas/contracts` + `@inferatlas/expr` (`pnpm run deps`).
- **Home**: version × model matrix, device filter, ok/triage/missing badges (icon + label, never
  color only), triage counts, links to model pages and to the diff for models with ≥2 snapshots.
- **Model page** (3 columns): parameter panel generated from `ir.params` (choices → segmented
  controls/selects, numeric → log/linear slider + input, validation errors, cross-param warnings
  e.g. `ep ≠ tp×dp`, reset per param/all, hardware preset selector); center graph with
  L0 → L1:<band> → L2:<node> drill-down (double-click/Enter/detail button), breadcrumb, layer-band
  strip, Esc up a level (keeps focus on the node you came from), `/` node search (cmdk);
  detail panel in design §3.5 order (class + permalink → in/out shapes, symbolic/numeric toggle →
  resident/unsharded bytes + sharding (inherited from parent spec) → FLOPs/HBM bytes both phases →
  intensity + roofline position → comm logical/bus/active → Ascend comparison card → rule id +
  raw formulas). Without a selection it shows the per-rank memory summary, config symbols,
  unmodelled list and accounting notes.
- **Graph visual language**: compute rect rx 6 (sans 600 name, mono class), group = stacked
  rect with ×N repeat, comm = hexagon crossing a dashed rank-boundary line with `group×degree`
  lane label and bus bytes (dashed when inactive), io = pill; mono edge labels on opaque
  background; residual dotted, KV dashed stub entering from above; thin heat bar (FLOPs/weights/
  HBM share of the view); single focus accent for the selected node and its incident edges;
  bottom legend strip with fidelity ledger (`collapsed_of`). Light/dark via semantic CSS tokens.
- **Ascend overlay** toggle: OOT/PATCH/QUANT/FUSED corner badges, dashed outer outline, `+n`
  roll-up on collapsed groups, comparison card (baseline vs Ascend symbol + permalinks, level,
  note, annotation id). Main graph colors never change.
- **Side views**: memory waterfall (weights → activation → non-torch/reserved → KV → rounding
  → budget → headroom → device, overflow warning, unmodelled list), KV capacity grouped stacked
  bars across TP choices (current highlighted, tokens/blocks/sequences/occupancy), roofline
  log-log (hardware preset, null peaks → explicit hidden state, clickable operator points),
  rank lanes (TP or EP ranks × view nodes, slice + resident bytes, collectives spanning lanes).
- **Live recompute**: env built from symbols → defaults → validated URL overrides; all node
  metrics recomputed with memoised compiled closures (unit test asserts < 16 ms per full
  recompute incl. memory ledger; typically ≈1 ms).
- **Diff page**: model/device/A/B pickers (+swap), per-view tabs with change counts, side-by-
  side canvases with ADDED/CHANGED/REMOVED node badges and accented changed edges, field-level
  change table (provenance commit/line ignored), model-level symbol/memory/param diffs.
- **URL state**: params, view, node, phase, overlay, side tab, shapes mode, heat metric,
  hardware preset; diff selection. Defaults omitted.
- **Data loading**: `data/index.json` + `data/<path>/{ir,view,report}.json` (view/report
  optional, HTML fallbacks treated as missing), or `window.__INFERATLAS__` in single-file mode.
  Error/empty states for missing cells, absent views, load failures, nothing to diff.
- **Tests**: Vitest 27 tests — every `fixtures/qwen3-30b-a3b/eval.json` oracle pointer reproduced
  through the UI's env binding; env validation; perf budget; graph build/label placement;
  navigation; diff; router-level component tests (matrix, model page recompute on tp change,

  selection, recompute, Esc, overlay, all side tabs, search, dark theme, diff, dense model empty

- Screenshots (Playwright, 1600×1000): `web/docs/screenshots/{home,model-light,model-overlay,
  model-kv,model-ranks,model-dark,diff}.png`.

## Not done / known gaps

- Labels on edges whose segment is narrower than the label are lifted above the node row
  (T4 layout uses 48px gaps; see requests). Wide single-row views pan horizontally at ≥0.9 zoom
  rather than shrinking text.
- Diff compares IR with each side's default parameters; no per-side parameter controls.
- KERNEL-level badges are shown (muted) whenever the overlay is on, because every fixture badge
  is KERNEL-level and hiding them by default would make the overlay empty. A level filter can
  be added once real annotations exist.
- No minimap (views are budgeted ≤9 nodes). Single-file HTML is ~1.8 MB (fonts in woff2+woff).

## Decisions

- Param overrides are top-level search keys (`?tp=4&T=8192`) via a zod `catchall`, validated
  against `ir.params`; invalid values are shown as rejected and the default is used.
- "Unsharded" bytes = the same `weight_bytes` expression with tp/pp/dp/ep = 1.
- Byte quantities use IEC units (GiB, matching vLLM logs); FLOPs/bandwidth use SI.
- The `fixture-prev` synthetic version exists only in the dev data copy, labelled
  "synthetic · diff demo", with notes stating it is not a real snapshot.
- Hardware presets are read from `data/hardware.json` (derived from catalog.yaml).
- `exactOptionalPropertyTypes` is disabled in web's tsconfig (shadcn/Radix props), all other
  strict options from the shared base remain.

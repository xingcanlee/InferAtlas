## Decisions

- Keep `target` and its hash for the observed replacement class/patch, adding
  explicit `{target, anchor_hash}` dependencies through a narrow Pydantic subclass
  rather than editing shared contracts outside ownership. No dependency added.
- Read source only at vLLM `544f182d9f0c9bfe8bd7645525951d5e3692a542` and Ascend
  `24a76e84394ae3427195e3715fc08e90769d398c`. All committed hashes were computed
  from those Git blobs. Unlisted helper definitions are not recursively hashed.
- Emit one existing `stale_annotation` item per invalid annotation, reporting
  the first changed target in symbol order and its old/new hashes. Duplicate
  targets and unresolvable declarations fail closed.
- Preserve one selected annotation id per node. Predicates remain caller
  selections from the shared TS evaluator; Python adds no second evaluator.
  Reselect modes from the original lowered IR to avoid accumulating links/tags
  from earlier selections; the merge API cannot infer their original ownership.
- Follow the pinned expert code: the reviewer’s fused-MC2 qualification applies
  to forced NZ, while the unfused branch can still convert via NZ policy. The
  rewritten note records both branches without adding another predicate lane.
- Retain `reviewed_by: pending`, source-based significance and no inferred
  physical memory/collective measurements from meta tensors or singleton groups.

```sh

export INFERATLAS_SRC=/home/cyberspace/projects/InferAtlas/experiments/a2_qwen3moe/src
uv run --project generator pytest -q
uv run --project generator ruff check generator/inferatlas/annotations generator/tests/test_annotations*.py
uv run --project generator ruff format --check generator/inferatlas/annotations generator/tests/test_annotations*.py
bash -n skills/inferatlas-maintain/scripts/*.sh
uv run --project generator --with pyyaml python /home/cyberspace/.codex/skills/.system/skill-creator/scripts/quick_validate.py skills/inferatlas-maintain
git diff --check
```

Source tests also discover experiment clones in normal checkout/worktree layouts.
Without clones, real-source integration tests explicitly skip; synthetic Git
unit tests remain self-contained. See `annotations/README.md` for API usage.

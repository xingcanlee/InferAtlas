## Decisions

- `collapsed_of` records the complete represented scope, including visible anchors.
  Subtract visible `ir_node`s to display the hidden/merged ledger. Node ids and source
  references remain IR-owned; layout does not reconstruct missing extraction facts.
- Collectives remain visible irrespective of their runtime `when`; parameter changes
  must not change coordinates. Conditions and PhaseExpr bytes remain in the linked IR.
- Separate shape-labelled Q/K/V edges are retained; only identical endpoint/kind/shape
  routes merge. Internal collapsed paths retain same-kind edge references, and KV or
  residual routes never get reclassified as data.
- Rank boundaries are local neutral segments perpendicular to flow, centered across
  each communication box. `rankBoundaryLanes(view, ir)` derives them from contract
  coordinates; they do not claim an actual physical-rank placement.
- Text metrics are frozen estimates: 14px sans advances, 8px mono advances, conservative
  full-em Unicode fallback. No platform font measurement or browser dependency.
- ELK's bundled engine uses Node `createRequire` because its CommonJS declarations
  disagree with NodeNext default-import typing. It executes without a worker thread.
- Runtime schema files remain authoritative and load relative to source/dist within
  the repository; this private Node tool is not a standalone browser bundle.

## Deviations from contracts

None. No schema fields were added. Bare `L1` is never emitted. Revised edge provenance,
shape and kind fields are present. Lane and style fields do not exist in View, so the
lane helper derives optional rendering geometry instead of extending serialized JSON.
The incomplete dense fixture limits generated detail as documented above.

## Verification and how to run

```sh
pnpm install --lockfile=false --registry=https://registry.npmmirror.com
pnpm --filter @inferatlas/contracts build
pnpm --filter @inferatlas/layout build
pnpm --filter @inferatlas/layout test
pnpm --filter @inferatlas/layout lint
pnpm --filter @inferatlas/layout inferatlas-layout ../../fixtures/qwen3-30b-a3b/ir.json -o /tmp/view.json
# Equivalent direct invocation:
node packages/layout/dist/cli.js fixtures/qwen3-30b-a3b/ir.json -o /tmp/view.json
git diff --check
```

All listed build/test/lint/CLI/diff checks passed. Tests build the contracts and CLI
before executing independent Node processes. To deliberately refresh snapshots:
`pnpm --filter @inferatlas/layout exec vitest run --update`.

Generated MoE view counts (nodes / edges): L0 8/7, L1:decoder 4/4, L2:attn 6/10,
L2:moe 7/7. Dense fixture: L0 7/6, L1:decoder 1/0. All respect the budget.

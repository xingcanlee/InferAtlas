## Decisions

- Preserve the authoritative IR/View schemas. Band click targets and rank lanes are
  derived library helpers for renderer integration, rather than serialized additions.
- `collapsed_of` continues to include the entire represented scope, including visible
  anchors. Subtract visible `ir_node`s to obtain the hidden/merged fidelity ledger.
- Keep collectives visible independent of runtime `when`, except the explicit L0
  budget merge. Runtime parameter edits must not move coordinates.
- Use DOWN flow for all built-in templates, with ELK wrapping to shorten long chains.
  The unwrapped retry is needed because the pinned ELK engine can return a diagonal
  residual edge after wrapping; both routes remain library-generated.
- Keep deterministic seed 1, sorted inputs, frozen text metrics, 4px grid geometry,
  sorted-key serialization, and no timestamps. Node 22.14+ supplies `findPackageJSON`; the layout package declares that minimum.

## Verification / how to run

From the repository root:

```sh
npm_config_registry=https://registry.npmmirror.com pnpm install --frozen-lockfile
pnpm --filter @inferatlas/contracts build
pnpm --filter @inferatlas/layout build
pnpm --filter @inferatlas/layout test
pnpm --filter @inferatlas/layout lint
pnpm --filter @inferatlas/expr test
pnpm --filter @inferatlas/contracts test
node packages/layout/dist/cli.js fixtures/qwen3-30b-a3b/ir.json -o /tmp/view.json
# Optional deployment override:
INFERATLAS_SCHEMA_DIR="$PWD/schemas" node packages/layout/dist/cli.js fixtures/qwen3-30b-a3b/ir.json -o /tmp/view.json
git diff --check
```

Layout tests build contracts and the CLI, check both fixtures in independent Node
processes, and test output preservation on errors. Refresh snapshots deliberately
with `pnpm --filter @inferatlas/layout exec vitest run --update`.

## How to run

See `docs/release.md` for complete mirrors/environment setup and the status-only
Pages staging script. From the repository root:

```sh
just release
# Expected exit 3 for actual DeepSeek H100 verification/layout failures.
# Outputs: dist/index.html and four inferatlas-qwen3-*.html files.
just hub --dir dist
# Refresh from current manifests; also exits 3 for the recorded H100 failure.

uv run --project generator inferatlas site \
  --build-root .cache/release/site-builds \
  --data-dir .cache/release/site-data --include-blocked
# Expected exit 2; successful Pages site with triage cells.

just lint && just test
uv run --project generator pytest generator/tests/test_defaults.py -q
INFERATLAS_RELEASE=1 pnpm --filter web e2e
```

Build artifacts are gitignored and intentionally uncommitted. Source, goldens,
progress/release docs, evidence and screenshots are committed on this branch.

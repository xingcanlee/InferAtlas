# T2 — expression DSL and review fixes

## Done

- Peggy grammar, committed standalone ESM parser, frozen AST cache and closure-based
  evaluator; exports `parse`, `evaluate`, `compile`, `free`, `format`, `formatHuman`,
  typed errors and an `evaluator` satisfying the shared `ExprEvaluator` interface.
- Lark production syntax/symbol validator; Python evaluation is confined to the
  private test-only reference interpreter. CPU/meta experiment scripts were read
  for context; no extraction or hardware execution was required.
- All T2-fix review findings addressed:
  - Bare builtin function names fail with `syntax` in TS `check()` and Python
    `_parse()`, including unselected branches. Added all seven names and nested,
    arithmetic and lazy-branch cases to the shared vectors.
  - External ASTs reject unknown node types/operators, malformed children/calls,
    invalid identifiers and non-number/non-boolean literals with `ExprError`
    (`syntax` or `type`); non-finite numbers retain `non_finite`. Tests cover both
    directly evaluated nodes and skipped branches.
  - Numeric `format` and `formatHuman` accept optional fourth `precision` argument:
    default four significant digits, trailing fractional zeros trimmed. Human
    formatting rounds after byte/FLOP scaling. Zero, negative values, small and
    large magnitudes, custom precision and invalid precision are tested. Rounding
    near `Number.MAX_VALUE` preserves scientific notation instead of `Infinity`.
  - Package README documents precision and the cross-language error contract:
    codes are stable; source positions and prose may differ between Peggy/Lark.
  - `@inferatlas/contracts` is a regular package dependency because public types
    are re-exported. Authorized lockfile update contains no registry URLs;
    a frozen pnpm install succeeds.
- 330 shared vectors consumed by Vitest/pytest. Fixture oracle values remain
  independently pinned, with fixture/vector drift checks and TP1/TP4 formula
  coverage. Vector regeneration is byte-identical; parser regeneration has no diff.

## Decisions / deviations from contracts

- The review explicitly requests rounded numeric formatting, superseding the
  original exact `Number.toString()` wording in T0-owned `docs/expr-dsl.md`.
  `evaluate` and `compile` retain full precision. Passing precision 17 to numeric
  `format` preserves a double when parsed back; shared numeric-vector checks use
  that precision. Symbolic formatting ignores environment and precision.
- Precision follows `Number.toPrecision`'s integer range 1–100. Invalid values
  raise `ExprError` with code `domain`. Output is deterministic and locale-free.
- `evaluator` uses `satisfies ExprEvaluator` to retain its inferred fourth argument
  while remaining compatible with the existing contract. Consumers explicitly
  typed as the old `ExprEvaluator` need T0's optional parameter declaration to
  select precision; named `format` and inferred `evaluator` support it already.
- Positions remain outside the wire AST in a WeakMap. Offsets are zero-based,
  line/column one-based; external AST errors without metadata use the origin.
  Error codes, rather than positions or prose, form the cross-language contract.
- Changes are confined to T2-owned implementation/package files, progress/request
  documentation, and the explicitly authorized root lockfile.

# T2 — expression DSL

## Done

- Peggy grammar and committed standalone ESM parser; deterministic regeneration at build.
  Exported `parse`, `evaluate`, `free`, `format`, `compile`, `formatHuman`, typed errors and
  an `evaluator` object satisfying the unchanged `ExprEvaluator` interface.
- Deeply frozen AST cache keyed by complete source strings; out-of-band source positions,
  numeric/type/domain checks, strict equality, lazy boolean/ternary evaluation and parse-time
  arity/literal checks across all branches. No eval/Function constructor or runtime dependencies.
- All eight dtype constants, exact bytes table, builtin rounding/aggregate functions, signed
  JavaScript remainder, right-associative powers and normative unary precedence.
- Lark equivalent grammar, production `validate(src) -> list[str]`, and positional
  `ExprSyntaxError`. Private test-only reference evaluator; production evaluation remains TS-only.
- 319 shared vectors, consumed by Vitest and pytest. Includes explicit precedence, booleans,
  laziness, all builtins/dtypes, every error category, canonical formatting and free symbols.
  Includes all six Qwen3-MoE oracle cases: TP1/TP4 weights, KV, FLOPs and shape dimensions,
  plus revised TP/DP/EP per-phase communication values. Fixture metadata uses JSON pointers.
  Expected fixture values are copied from eval.json, not calculated by the implementation.
- Tests check vector drift against fixture IR/oracle and evaluate all fixture metric/shape
  formulas at TP1/TP4. AST input, immutability, reserved bindings, inherited env properties,
  precise multiline positions and closure reuse are covered.
- Standalone Node benchmark: 10,000 distinct compiled sources based on actual fixture formulas,
  full env/type/domain checks, checksum validation, three warmups and seven measured batches.
  Median measured **13.37 ms** here; enforced acceptance limit is **50 ms**.

## Decisions / deviations from contracts

- No contract deviations. The contract's `format(src, 'numeric')` returns the exact plain
  decimal string, so requested human units are provided by a separate `formatHuman` export:
  automatic B/KiB/MiB/GiB, explicit FLOP/GFLOP/TFLOP. `compile` is another named export;
  the existing interface is unchanged.
- Symbolic formatting fully parenthesizes operators, normalizes whitespace and preserves
  identifiers; shared vectors pin examples. No simplifier or algebraic rewrite was added.
- Source positions use zero-based offsets and one-based lines/columns. Metadata stays in a
  WeakMap because the public AST union has no location fields. External AST/environment
  binding errors without source metadata use the origin. Cached ASTs are deeply frozen;
  cache entries live for the module lifetime (a finite set of IR sources is the intended use).
- Python's private `_reference.py` is imported only by tests, is not publicly exported and
  is explicitly documented as unsuitable for production metric evaluation.
- Peggy and Vitest are pinned dev dependencies. The generated parser is lint-suppressed;
  all generated output is formatted by the pinned workspace Biome. Non-null assertions in
  builtin dispatch are justified by prior arity/membership checks.

## How to run

```sh
pnpm install --lockfile=false --registry=https://registry.npmmirror.com
UV_INDEX_URL=https://mirrors.aliyun.com/pypi/simple/ uv sync --project generator --locked --python 3.12
pnpm --filter @inferatlas/expr test
uv run --project generator pytest generator/tests/test_expr.py
pnpm --filter @inferatlas/expr benchmark
pnpm exec biome check packages/expr
uv run --project generator ruff check generator/inferatlas/expr generator/tests/test_expr.py packages/expr/scripts/vectors.py
uv run --project generator ruff format --check generator/inferatlas/expr generator/tests/test_expr.py packages/expr/scripts/vectors.py
```

Use normal frozen pnpm installs after the root lockfile owner applies the request.
API examples and regeneration commands are in `packages/expr/README.md`.

## How to run

From the repository root with the existing Python/pnpm environments and check tools:

```sh
UV_INDEX_URL=https://mirrors.aliyun.com/pypi/simple/ uv run --project generator --frozen pytest .github/actions/tests
node --test .github/actions/tests/*.test.cjs
PATH="$PWD/.cache/checks/bin:$PATH" .cache/tools/actionlint -config-file .github/actions/actionlint.yaml .github/workflows/*.yml
UV_INDEX_URL=https://mirrors.aliyun.com/pypi/simple/ uv run --project generator --frozen ruff check --config generator/pyproject.toml .github/actions
UV_INDEX_URL=https://mirrors.aliyun.com/pypi/simple/ uv run --project generator --frozen ruff format --check --config generator/pyproject.toml .github/actions
pnpm exec biome check .github/actions
git diff --check
```

`--frozen` preserves the canonical PyPI lock; existing locked artifact URLs are not
redirected by the mirror environment variable.

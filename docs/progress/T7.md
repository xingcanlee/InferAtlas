## Decisions and deviations from contracts

- Chose the permitted **state branch** option instead of modifying the catalog. It stores
  both the handled-pair ledger and prior public JSON so deployments preserve old snapshots.
- First polling run backfills all compatible published releases; missing historical
  pairing declarations are skipped with a warning. No unverified tag pairing is guessed.
- Nightly deliberately uses actual main/main, as requested, and does not publish.
  Polling publishes verified-main pairs, following the design's compatibility evidence.
- Snapshot release identity includes the full InferAtlas commit along with both upstream
  commits, preserving revised generator/catalog/rule output without overwriting releases.
- The shared command names are unchanged. Their detailed flags/output directory contract
  was absent from T0, so the exact integration requirements were recorded rather than
  changing another task's CLI or web files. No schema/IR contract was changed.
- Calibration uploads raw evidence for later verifier/maintainer processing rather than
  committing hardware data outside this task's owned paths. Raw runtime logs can contain
  upstream timestamps; generated ledger, JSON summaries and manifests add no timestamps.
- Optional CPU dependencies mirror the experiment's best-effort behavior. Required
  dependencies, imports, extraction, schema, source, coverage and golden gates remain
  mandatory. No old Qwen3-8B dimensions are embedded in CI.

## How to run

On an integrated checkout with its lockfiles:

```sh
.cache/tools/actionlint -config-file .github/actions/actionlint.yaml .github/workflows/*.yml
uv run --project generator ruff check --config generator/pyproject.toml .github/actions
uv run --project generator ruff format --check --config generator/pyproject.toml .github/actions
uv run --project generator pytest .github/actions/tests
node --test .github/actions/tests/*.test.cjs
```

The isolated local validation used `uv venv --python 3.12 .cache/checks` and installed
`pytest`, `jsonschema`, `ruamel.yaml`, `ruff`, `shellcheck-py`, and `pyflakes` there through
the requested PyPI mirror. This avoided creating unowned project lockfiles. Run the
tests with `uv run --no-project .cache/checks/bin/python -m pytest .github/actions/tests`;
add `.cache/checks/bin` to `PATH` for actionlint's embedded-script checks.

For live operation, use the dispatch examples and setup requirements in `docs/ci.md`.

Branch `task/U3` = main + reviewed generator branch `task/S1`. UI-only changes (`web/**`,
`packages/arch-ui/**`, `fixtures/arch-ui/**`); generator/schemas/contracts untouched. Generator
data issues found on the way are in `docs/requests/U3.md`.

## Done

### 1. Generated contract types
- `web/src/lib/arch-types.ts` deleted; every consumer imports `Arch`, `ArchBand`, `ArchBlock`,
  `ArchComponent`, `ArchStage`, `ArchModuleStage`, `ArchStackStage`, `ArchSublayer`,
  `ArchTensor`, `ArchIO`, … from `@inferatlas/contracts` (params are `ArchTensor`; the local
  `ArchParam` alias is gone). `tsc` passes.
- Thin normalize layer kept in `lib/arch.ts#normalizeArch` for old data only: deprecated
  `sliding_window` / `sparse` attention variants → head-sharing scheme + extras, missing v1.2
  `io.internals` → `[]`, missing `flags` → `[]`, missing v1.1 `placement` → `aside` for `other`
  stages. Real v1.3 output passes through structurally unchanged.

### 2. Fixtures are real generator output, schema-valid
- `fixtures/arch-ui/build.mjs` rewritten: copies the A2 `arch.json` of deepseek-v3,
  deepseek-v4-flash, gpt-oss-120b, qwen3-8b, qwen3-30b-a3b, qwen3-next-80b-a3b byte-for-byte from

  (was `s1/deepseek-v4-flash.trimmed.json`, which the schema test could not map to a schema).
- `uv run --project generator pytest generator/tests/test_schema_contracts.py -q`: 40 passed
  (was 7 failures).
- `.release-data/` added to `.gitignore`.

### 3. Real-data site, checked in a browser (1440×900)
All 32 cells: figure renders, no page/console errors, fits the canvas at ≥ 0.9 scale, layer
detail lists inputs/outputs/internals/params. Fixes made for real data:
- **VLM encoder branch** (Llama-4-Scout, MiniMax-M3): stages before the token embedding (patch
  embedding, vision layers, pre/post norms, adapter, projector) are drawn as a second input
  branch left of the spine that merges into the token embedding (new arch-ui primitive
  `FigureMerge`: equal side columns keep the spine centred, elbow wire + junction dot, label =
  last encoder output). The branch is one collapsible "Vision encoder" frame with a chain
  summary ("Llama4UnfoldConvolution → LayerNorm → 34× MHA attn · dense MLP → …"); it opens on
  demand or when the selection is inside it, and its own vision-layer stack stays collapsible.
  Previously the vision chain sat on the main spine under `input_ids` (wrong dataflow) and the
  figure overflowed the window.
- **Stage labels** (`stageLabel`): the emitter's "Token embedding" / "Final norm" on vision stages
  and raw-id labels of `other` stages are replaced by the humanised module name; the overview's
  Dataflow groups encoder stages under "Vision encoder".
- **Long class names**: module paths, class names, Ascend replacements and note texts wrap at dots
  (`QualifiedName` with `<wbr>`); notes no longer overflow the 400 px panel.
- **Empty IO** (generic stages / MiniMax-M3 sparse attention): "not derived (unknown for this
  component)" instead of "none" (contract: empty = unknown).
- **De-duplicated notes**: a sublayer's notes include those targeted at the same-id, same-class
  sublayer of any band in the stack (`subNoteTargets`), so DeepSeek-V4 mHC warnings badge the
  drawn period bands and show in every layer's detail (they are emitted on band 0 only).
- Single routing group (`n_group: 1`, GLM-4.5/4.6) no longer shows a "1/1 groups" chip.
- Spine edges are `md` (DeepSeek-V4 now fits at 0.9 instead of overflowing by 4 px); edges into
  a collapsed secondary stack are `xl` so the tensor label never meets the stack legend; edge
  labels sit on the canvas colour (wires never cross the text; node badges still paint above).
- Layer selector / panel links scroll the selected band into view when the figure scrolls.
- Verified as-is with real data: DeepSeek-V4 mHC residual bus with `hc_head_op` before the final
  norm (array order), compact band list (2 prefix bands + (÷128, ÷4 + indexer) × 20), gpt-oss
  SWA/full alternation ((1× GQA SWA + 1× GQA) × 18), Qwen3-Next (3 linear + 1 GQA) × 12,
  Llama-4 (3× chunked + 1× GQA) × 12, MiniMax-M3 generic sublayers (unknown residual → plain
  chain, generic boxes with status/notes).

Branch `task/U1`. Contract: `docs/arch-contract.md` (arch.json v1).

## Done

### `packages/arch-ui` (`@inferatlas/arch-ui`)
shadcn-style, presentational only: typed props, `cva` variants, Tailwind v4 classes, no data
fetching, no expression parsing, no per-model drawing code. Tokens in `src/theme.css` layer
paper-figure role tints (norm / attention / ffn / router / shared expert / embedding / head /
generic / frame / wire, light + dark) over the host's semantic tokens (`--foreground`,
`--border`, `--focus`, `--ok/--warn/--bad`, `--overlay` …). The web app imports the CSS and adds
`@source` for the package; Vite/TS resolve the package to `src/` (no build needed for dev),
`pnpm -r --filter "@inferatlas/*" build` emits `dist/` with `tsc`.

### Architecture page (`web/`)
- `/m/:version/:device/:model` now has two tabs: **Architecture** (default) and
  **Graph & analysis** (the existing workspace, unchanged, `src/pages/model/GraphWorkspace.tsx`).
  `?tab=graph|arch`; links carrying graph-only keys (`view`, `node`, `side`, `overlay`, `heat`,
  `phase`, `hw`) open the graph tab, so old deep links keep working.
- Figure (`src/components/arch/ArchFigure.tsx`) is the only arch.json → arch-ui mapping and is
  generic over the contract. Stage order from `stages`; `other` stages go to the side aside.
  Bands fold into pattern groups (`lib/arch.ts#stackItems`); residual segments come from the
  block (`blockSegments`: explicit `residual_add` closes a branch, otherwise ⊕ is inferred after
  mixer/ffn; post-norm keeps the norm on the main stream).
- Detail panel: overview (model, dataflow, notes), **layer detail** (every sublayer: module path
  rewritten to the chosen layer, class, source link, status, Ascend replacement, inputs/outputs
  and params with symbolic shape `=` numeric shape, param bytes, notes) or stage detail.
- Layer selector (input, ←/→ buttons, ↑/↓ keys): any layer index resolves to its band (and to the
  period representative inside a pattern group). URL: `?layer=42&sub=mlp` / `?stage=lm_head`.
  Esc returns to the overview.
- Symbols editor: every arch symbol is editable; overrides live in the URL (`?T=8192&tp=8`) and
  are evaluated with `web/src/lib/expr.ts` (the existing `@inferatlas/expr` adapter).
- Fit: the canvas scales the figure down (never up, min 0.6) to fit; toggle to 100%. At
  1440×900 the four fixtures render at 90–100%, at 1280×800 at ≈0.77–0.80, at 1920×1080 100%.
- Notes/triage are badges on the affected component (status dot + note count) and lists in the
  panel; nothing blocks rendering. Empty states: snapshot without `arch.json` (arch tab, with a
  button to the graph tab) and structure-only cell without `ir.json` (graph tab).
- Data: `loadCellBundle` now returns `{bundle?, arch?}` (ir.json optional, arch.json optional,
  error only if both are missing); single-file inline includes `arch.json`.
- Home: every cell with a `data_path` was already a link regardless of status; the new
  structure-only triage cells (DeepSeek-V3, Qwen3-Next) are linked too (covered by tests).

## Decisions
- **Layout: flex/CSS + tiny SVG glyphs, not xyflow / elk.** Paper figures are a single vertical
  spine with nested frames; the only non-trivial geometry is the residual skip line, which is a
  bordered box whose right edge is the spine (`ResidualBranch`), so it follows any content height
  without measuring. Text stays real DOM (crisp, selectable, accessible, focusable buttons), the
  layout is deterministic, works in jsdom tests and the single-file build, and needs no
  pan/zoom state. A transform-only fit (`FitBox`) handles small windows.
- Top-to-bottom dataflow (reads naturally on the web; Transformer paper is bottom-up).
- arch-ui does not depend on `@inferatlas/expr` or the contract: the host injects
  `evaluate(expr)`; props are presentational (camelCase). Only `web/src/components/arch/*` knows
  arch.json.
- Heterogeneous bands are drawn side by side inside the stack (each with its own `N×`), periodic
  patterns as one group with a right-hand `×repeats` bracket so it never reads as a band count.
- Graph workspace default: analysis panel opens by default from 940 px window height (was 900)
  because the new 40 px tab header sits above it; keeps the 1440×900 graph-fit guarantee.

## How to swap to the contract types (when S1 lands)
1. Delete `web/src/lib/arch-types.ts` and re-export the generated types under the same names
   (`Arch`, `ArchBand`, `ArchBlock`, `ArchSublayer`, `ArchComponent`, `ArchModule`, …) from
   `@inferatlas/contracts`, or rename imports — every consumer imports only from that file.
2. Run `pnpm --filter web exec tsc -p tsconfig.json`; differences surface in `lib/arch.ts`,
   `components/arch/*`. Interpretations to reconcile are listed in `docs/requests/U1.md`.
3. Point `sync-data.mjs` demo mode at S1 goldens if wanted; release mode already copies whatever
   `arch.json` the pipeline puts next to `ir.json`.

## Review round 1 (rebased on main incl. contract v1.1)
Must-fix:
1. **Folding** (`web/src/lib/arch.ts`): structural signature = residual style + per sublayer
   (role, component kind/variant, short class); ids, paths, sources and sizes ignored. Labelled
   runs (shared `pattern`) fold by smallest period; unlabelled runs fold when a period of ≤ 6
   bands repeats ≥ 2× (auto label, e.g. "3× linear attn + 1× GQA attn"). Stacks that would still
   draw > 4 blocks side by side switch to a **compact band list** (`BandList`/`BandCard`, wrapping)
   plus the selected (or first) band's full block, so width never explodes.
2. **Dark screenshots**: the app persists its theme in localStorage; `e2e/arch.spec.ts` now seeds
   the stored theme, reloads and asserts `html.dark` before shooting. Screenshots regenerated and
   reviewed.
3. **arch.json failures are isolated**: `loadArch` validates (fetch + inline) and
   `loadCellBundle` returns `archError` instead of rejecting; the Architecture tab shows the error
   (`arch-error`) and the graph tab keeps working.

Contract v1.1 alignment (local types in `arch-types.ts`, fixtures regenerated):
`residual_add` → `component/module: null` with ids `residual_1/residual_2`; band-relative
sublayer ids with `module.path` substitution; note targets `<band>/<sublayer>` band-wide;
`other` stages `placement: "spine" | "aside"` (aside = side branch, legacy default aside);
`router.groups {n_group, topk_group}`; attention extras `sliding_window` / `index_topk` (chips)
and linear fields (`num_k_heads`, `num_v_heads`, `head_k_dim/head_v_dim`, `conv_kernel`,
`output_gate`); top-level `rope.partial_rotary_factor`; symbols include `T`/`tp`; class names
fully qualified in data, short in the figure, full (wrapping) in the detail panel.

Nits:
- Side heads use the new `FigureBranch`: a dashed connector leaves a junction dot on the spine
  node (LM head row) and does not change the spine row height (`FigureAside` removed).
- Legibility: minimum figure text raised to 10px and the fit floor to 0.9 (≥ 9px effective);
  stack title moved onto the frame border, tighter edges/padding. 1440×900: all four fixtures fit
  at 93–100%; 1280×800: 8B/30B fit, DeepSeek/Qwen3-Next scroll slightly at 0.9. Detail panel is
  360px below 1440px width.
- MoE: highlighted experts are marked illustrative ("e.g." + title, `data-illustrative`).
- Layer selector shows "of N layers"; the `?layer=` key is an ordinal over all stacks
  (`layerSlots`), shows the stack label with several stacks, and "No decoder layers" without one.
- Only runtime symbols (`T, S, tp, dp, ep, pp, batch, context`) are editable/overridable; model
  dimensions are listed read-only.
- Esc on the Architecture tab ignores events while the command palette, a dialog, menu or listbox
  is open (or already handled); the header's "Find node" button is shown only on the graph tab.

## U2 — contract v1.2 UI (branch `task/U2`, from main incl. "Contract decisions v1.2")
UI only (local types `web/src/lib/arch-types.ts` + fixtures); generator/schemas/contracts untouched.

1. **IO internals** (`io.internals`): sublayer/stage detail shows a separate "Internal tensors · N"
   group (q/k/v/o, MLA latents, compressed KV, router logits, top-k ids/weights, per-expert
   tensors); Outputs list only what leaves the sublayer. In the figure an **Internals** toolbar
   toggle (off by default) adds up to 3 key internals (`keyInternals`: q/k/v, latents, routing) as
   small non-interactive `TensorChip`s inside Attention / MoE (evaluated shape in the title).
2. **Notes**: the overview groups notes by `triage_kind` (`groupNotes`, warn-heavy groups first,
   plain notes last) with warn/info counts; warn notes are listed with their target, info notes
   are collapsed behind a `<details>`. Figure badges now count **targeted warn notes only**
   (`noteMarker`); info notes never badge the figure.
3. **Compressed attention + mHC**: `Attention` shows `KV ÷N` (`compress_ratio`) and
   `indexer top-K` chips; `compress_ratio`/`indexer` (and MoE router scoring, e.g. hash vs
   learned) participate in band signatures and in labels (`attentionLabel`: "MQA attn ÷4 +
   indexer"). Residual `"hyper_connection"` renders a distinct style: a multi-lane
   `ResidualBus` (n lanes, n from the `mhc_*` input shape `[T, n_hc, H]`) down the block with
   `MhcBox` steps (H_pre / H_post · H_res) in dataflow position, each wired to the bus
   (`HyperBranch`; `blockSegments` returns `hyper` segments, fused post/pre supported).
4. **Stage order**: figure uses `canonicalStages` (embedding → stacks → final norm → lm_head →
   spine others; aside others last). The decoder feeding the final norm is the primary stack;
   other stacks (vision / encoder) render as collapsible `BlockStack`s (collapsed summary,
   auto-open when they hold the selection).
5. **Fixtures** (`fixtures/arch-ui/build.mjs`): all fixtures carry `io.internals`; Qwen3-Next
   notes de-duplicated to stack level. New:

6. **Home**: rows are models grouped by family (Dense / MoE / MLA / Hybrid / …, with counts),

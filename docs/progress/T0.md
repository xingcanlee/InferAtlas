## Decisions and deviations from examples

- dev-plan §3 takes precedence over older design examples. Snapshot is structured everywhere,
  including triage/report. SourceRef includes repo/file/line/commit/symbol; lines are script-derived.
- IR symbols, metrics, dimensions, parameter numeric defaults/bounds and layer indices are
  expression strings. Source line numbers are integer provenance. Raw extract/catalog/eval/view
  quantities remain JSON numbers. `memory.unmodelled` is a prose exclusion list.
- Tensor slots are `{name, shape, dtype}` arrays; shape is an expression array or an explicit
  `{prefill,decode}` shape object. Rules use these slots and `{prefill,decode}`
  work/traffic expressions, with no scalar or serialized-array shorthand. Wire aliases are
  `class`, `in`, `from`; Python attributes are documented in contracts README.
- `Extract.parallel.ep` is upstream's boolean; IR `ep` is an integer degree (1 disables EP,
  enabled degree is tp*dp at this pinned PCP=1 revision). MoE expert TP is flattened over
  tp*dp when EP is disabled. DP replicas do not multiply rank-local resident weights.
- Fixture PP choices divide L, so the heaviest equal-size stage includes final norm/head;
  arbitrary nonuniform PP requires later rank-specific lowering. Group summaries must not be
  summed with descendants. Decoder children are one representative layer, while decoder metrics
  summarize L/pp resident layers.
- Main config revision is `inline:sha256:<canonical JSON digest>` because catalog configs are
  local pinned inputs, not an invented HF commit. DeepSeek config is a construction subset
  (bf16, no quantization metadata), not a downloaded checkpoint manifest.
- Runtime env version strings in the checked-in experiment are stale relative to the verified
  source checkout. Source refs are resolved by AST from actual pinned clones (vLLM 544f182,
  ascend 24a76e8); experimental shape/class facts are preserved. No FakeProcessGroup was added.
- Curated index statuses/paths and triage entries are independent UI examples, not publication
  claims or on-disk data-directory guarantees. Annotation example is not maintainer review.
- Shared TS base lives under packages/contracts to respect root-path ownership. Generated types
  use `*.generated.ts` so the Index schema cannot overwrite the handwritten barrel.
- Hardware units are decimal GB/GB/s and dense 10^12 operations/s (INT8 is TOPS in the common
  peak field). 310P uses LPDDR4X, not HBM; H100 sparse tensor peaks are divided by two for dense.

## How to run / handoff

Run `just setup`, `just schemas`, `just test`, `just lint`, `pnpm -r build` from repo root.
Or `cd generator && uv run pytest` / `uv run python -m inferatlas.schema.export`.
Public TS types come from `@inferatlas/contracts`; Python models from `inferatlas.schema`
(or shared nested types from `inferatlas.schema.models`). Always serialize with aliases.
Read `packages/contracts/README.md` and `docs/expr-dsl.md` before implementing downstream tasks.

Optional curated-fixture regeneration (requires pinned source clones, no imports/weights):
`INFERATLAS_SRC=/path/to/directory-containing-vllm-and-vllm-ascend uv run --project generator python fixtures/build.py`.
The worktree environment's provided clone location is the default. Do not treat the fixture
builder as the production extractor/lowerer. Keep the generated schemas and TS files committed.


## T0-fix review resolution (new commit)

Done: all eleven review items are addressed in the owned contracts, builder, generated
schemas/types and fixtures; no review item remains open. The existing T1–T7/F1 stubs remain
handoff boundaries.

- Correct Qwen3-8B pinned subset: 36 layers, 12288 dense intermediate, H=4096,
  32 query / 8 KV heads, D=128, V=151936, untied embeddings, epsilon=1e-6,
  theta=1000000. Canonical config_rev is recomputed from that subset. The weight ledger
  includes replicated per-head Q/K norms and totals 16,381,470,720 bf16 bytes at TP1.
  Equal PP choices now divide 36.
- MoE dispatch/combine requires ep>1 AND dp>1; final reduction uses group tp of size tp,
  T*H / S*H elements, activated by tp>1 OR ep>1. The assumed path has PCP=SP=1,
  skip_final_all_reduce=false, output not already reduced by a fused kernel. Fused transport,
  routing metadata and DP gather/scatter remain outside this fixture estimate.
- Both model fixtures include embed.reduce and logits.gather. Default logits dtype is dtype_a,
  matching the default model/head dtype, including head output slots and HBM/comm bytes.
  Prefill LM head uses batch last-token rows; decode uses S, with explicit phase shapes and
  parallel.tp.dim=out. An fp32 head override needs corresponding dtype-aware lowering.
- Rule.context explicitly names required GLOBAL bindings. Extraction keeps per-rank head/
  partition facts; lower recovers global constants from config or observed TP before a rule
  divides by runtime tp. Constructor attrs that already contain global sizes remain facts.
  The generic row rule covers o_proj AND down_proj, with worked TP4 examples in its notes
  and docs/expr-dsl.md. Observed row partition attrs are included in the extract examples.
- Rules may emit comm sub-nodes with stable `<module-node-id>.<suffix>` ids; duplicate
  suffixes and attaching comm alongside emissions fail model validation. The fixture uses
  attn.o.reduce and moe.experts.{dispatch,combine,reduce}; compute nodes carry no duplicate
  comm. Module-to-template mapping, synthetic operations and multi-band prefixes are specified
  in docs/expr-dsl.md. Emissions inherit the module's rule id/provenance.
- ViewEdge now requires ir_edges and kind and optionally copies an IR tensor shape as label.
  Collapsed routes retain intervening collectives. L1:decoder replaces bare L1; schema/model
  reject bare/empty/whitespace band ids. Provenance/labels/kinds are checked against fixture IR.
- Comm logical_bytes AND bus_bytes are PhaseExpr objects. Logits gather logical bytes use
  local padded vocabulary shards. Its default gather bus estimate is rank-average outgoing
  bytes; rank 0 receives the other shards. Platform all_gather uses a different documented
  factor. This explicit convention is necessary because gather traffic differs across ranks.
- Eval keys are JSON pointers over a nodes-by-id projection; dots within ids remain literal.
  Both Pydantic and JSON Schema reject legacy dotted keys. The oracle includes distinct
  batch=2/S=3 and four additional EP/DP communication cases.
- DType and the normative bytes() table include int32=4 and int64=8; dtype_ids is a dtype
  parameter. No alternate runtime evaluator was added to the approved T2 stub.
- generator/uv.lock and pnpm-lock.yaml are included; .npmrc no longer sets lockfile=false.
  `uv sync --locked --python 3.12` and `pnpm install --frozen-lockfile` both pass using mirrors.

Contract changes: PhaseShape, Rule.context/emits/RuleEmission, ViewEdge.ir_edges/kind/label,
strict L1 ids, per-phase Comm quantities, gather op, pointer-only eval keys and integer dtypes

## Decisions and deviations from examples

- dev-plan §3 takes precedence over older design examples. Snapshot is structured everywhere,
  including triage/report. SourceRef includes repo/file/line/commit/symbol; lines are script-derived.
- IR symbols, metrics, dimensions, parameter numeric defaults/bounds and layer indices are
  expression strings. Source line numbers are integer provenance. Raw extract/catalog/eval/view
  quantities remain JSON numbers. `memory.unmodelled` is a prose exclusion list.
- Tensor slots are `{name, shape, dtype}` arrays. Rules use these slots and `{prefill,decode}`
  work/traffic expressions, with no scalar or serialized-array shorthand. Wire aliases are
  `class`, `in`, `from`; Python attributes are documented in contracts README.
- `Extract.parallel.ep` is upstream's boolean; IR `ep` is an integer degree (1 disables EP,
  enabled degree is tp*dp at this pinned PCP=1 revision). MoE expert TP is flattened over
  tp*dp when EP is disabled. DP replicas do not multiply rank-local resident weights.
- Fixture PP choices divide L, so the heaviest equal-size stage includes final norm/head;
  arbitrary nonuniform PP requires later rank-specific lowering. Group summaries must not be
  summed with descendants. Decoder children are one representative layer, while decoder metrics
  summarize L/pp resident layers.
- Main config revision is `inline:sha256:<canonical JSON digest>` because catalog configs are
  local pinned inputs, not an invented HF commit. DeepSeek config is a construction subset
  (bf16, no quantization metadata), not a downloaded checkpoint manifest.
- Runtime env version strings in the checked-in experiment are stale relative to the verified
  source checkout. Source refs are resolved by AST from actual pinned clones (vLLM 544f182,
  ascend 24a76e8); experimental shape/class facts are preserved. No FakeProcessGroup was added.
- Curated index statuses/paths and triage entries are independent UI examples, not publication
  claims or on-disk data-directory guarantees. Annotation example is not maintainer review.
- Shared TS base lives under packages/contracts to respect root-path ownership. Generated types
  use `*.generated.ts` so the Index schema cannot overwrite the handwritten barrel.
- Hardware units are decimal GB/GB/s and dense 10^12 operations/s (INT8 is TOPS in the common
  peak field). 310P uses LPDDR4X, not HBM; H100 sparse tensor peaks are divided by two for dense.

## How to run / handoff

Run `just setup`, `just schemas`, `just test`, `just lint`, `pnpm -r build` from repo root.
Or `cd generator && uv run pytest` / `uv run python -m inferatlas.schema.export`.
Public TS types come from `@inferatlas/contracts`; Python models from `inferatlas.schema`
(or shared nested types from `inferatlas.schema.models`). Always serialize with aliases.
Read `packages/contracts/README.md` and `docs/expr-dsl.md` before implementing downstream tasks.

Optional curated-fixture regeneration (requires pinned source clones, no imports/weights):
`INFERATLAS_SRC=/path/to/directory-containing-vllm-and-vllm-ascend uv run --project generator python fixtures/build.py`.
The worktree environment's provided clone location is the default. Do not treat the fixture
builder as the production extractor/lowerer. Keep the generated schemas and TS files committed.

## Decisions

- Retained the pinned installer for supported tools and installed actionlint
  directly instead of changing unrelated action versions.
- Kept push discovery limited to each workflow's own file and excluded static
  and state branches. Job guards prevent pipeline execution on discovery events.
- Manual poll/nightly dispatch bypasses the schedule-only variable gate but is
  restricted to the default branch. Workflow-level disabling remains effective
  until a maintainer re-enables them after merging C1.
- Publication is separately opt-in, allowing CI and branch-based Pages before
  the workflow deploy path is enabled.
- Read the design/development plan and skimmed the verified experiment approach:
  CPU/meta extraction, real single-rank gloo with TP shim, upstream Ascend mocks,
  no model weights or real NPU execution.

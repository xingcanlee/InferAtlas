## Decisions / deviations from contracts

- This task supersedes the earlier approved T3-contract communication convention:
  default dispatch/combine use DP, with logical bytes equal to the full gathered
  tensor, consistent with `linear.column`. No schema change is required.
- The independently calculated fixture oracle covers dp=1/2/4, TP boundary cases,
  both phases, logical bytes and bus bytes. Shared vectors are generated from it;
  no Python production expression evaluator was added.
- The scope excludes sequence parallelism and PCP, as stated in the existing
  pinned MoE contract. Router scores, IDs, padding and transport workspace remain
  excluded from these hidden-state communication estimates.
- Retained the existing curated graph labels and routed dispatch output. Changing
  their presentation required a T4-owned layout snapshot update; the corrected
  collective group/bytes and gathered combine input do not affect graph layout.

## How to run

```sh
export UV_INDEX_URL=https://mirrors.aliyun.com/pypi/simple/
export INFERATLAS_SRC=/home/cyberspace/projects/InferAtlas/experiments/a2_qwen3moe/src
export INFERATLAS_PY=/home/cyberspace/projects/InferAtlas/experiments/a2_qwen3moe/.venv/bin/python
npm_config_registry=https://registry.npmmirror.com pnpm install --frozen-lockfile
just schemas
uv run --project generator python fixtures/build.py
uv run --project generator python packages/expr/scripts/vectors.py
just test
pnpm --filter '!web' --filter '!inferatlas' -r build
just lint
```

All Python commands use the generator's uv-managed Python 3.12 environment;
upstream extraction subprocesses use the supplied CPU interpreter and mocks.

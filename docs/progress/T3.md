- Backend selection is a lowering option, not an interactive IR boolean:
  Comm.op is a static enum. This avoids extra communication nodes exceeding
  layout's shared-expert budget. Changing backend requires lowering again;
  TP/DP/EP values still recompute within the selected backend's IR.
- Child traffic conserves the corrected total rule. The former group formula
  omitted intermediate activation reads/writes and TP-replicated hidden traffic;
  that undercount is corrected rather than preserved. Weight traffic still uses
  the same touched-expert estimate, and weights/FLOPs are not counted twice.
- Sampler uses an explicit 22 B/element ledger for bf16 (roughly the requested
  20 B/element), rather than retaining the old 4 B/element estimate.
- No schema, catalog, root CLI, layout or annotation ownership changes. The
  approved fixture/DSL/vector updates are committed with T3's changes.

## How to run

```sh
export UV_INDEX_URL=https://mirrors.aliyun.com/pypi/simple/
# INFERATLAS_SRC: directory containing pinned vllm and vllm-ascend clones.
# INFERATLAS_LOWER_EXTRACTS: optional CPU/meta cache, including deepseek-v3/.
uv run --project generator pytest generator/tests/test_lower.py generator/tests/test_rules.py
uv run --project generator python fixtures/build.py
uv run --project generator python packages/expr/scripts/vectors.py
pnpm --filter @inferatlas/expr test
just test
just lint
uv run --project generator python -m inferatlas.lower \
  --extract fixtures/qwen3-30b-a3b/extract.json --out /tmp/t3-default
uv run --project generator python -m inferatlas.lower \
  --extract fixtures/qwen3-30b-a3b/extract.json --moe-a2a --out /tmp/t3-kernel
```

Use Python 3.12 through uv and install Node dependencies with
`npm_config_registry=https://registry.npmmirror.com pnpm install --frozen-lockfile`.
For upstream-free runs, source/cache integration tests skip explicitly.

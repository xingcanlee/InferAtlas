## Decisions / deviations from contracts

- Chose one optional predicate per parameter, keeping the IR top-level fields
  unchanged. The predicate may refer to any bound symbol/control, so consumers
  must recheck all predicates even when a different control changed. No Python
  production evaluator or expression-valued literal choices were introduced.
- VersionMismatch.vllm_version records the resolved base version, or the raw
  explicit version/snapshot tag when resolution fails. expected_ranges is the
  sorted unique list of authoring PEP 440 vLLM rule ranges. The enclosing snapshot
  retains the immutable commit, including when a development tag is unresolved.
- Consumer environment binding belongs to T6/F1 and was documented for its owners.
  Existing context/path/parameter failures continue using golden_diff because
  this approval only adds the dedicated version failure variant.
- No other contract deviations. Resident weight/memory/communication formulas
  and backend selection retain the previously approved T3-fix behavior.

## How to run

```sh
export UV_INDEX_URL=https://mirrors.aliyun.com/pypi/simple/
export INFERATLAS_SRC=/home/cyberspace/projects/InferAtlas/experiments/a2_qwen3moe/src
export INFERATLAS_PY=/home/cyberspace/projects/InferAtlas/experiments/a2_qwen3moe/.venv/bin/python
# Optional: INFERATLAS_LOWER_EXTRACTS points to an existing CPU/meta extract cache.
just schemas
uv run --project generator python fixtures/build.py
uv run --project generator python packages/expr/scripts/vectors.py
just test
pnpm -r build
just lint
```

Use Python 3.12 through uv and install Node dependencies with
`npm_config_registry=https://registry.npmmirror.com pnpm install --frozen-lockfile`.
The full test command uses only CPU/meta and upstream CPU mocks; no NPU or weights.

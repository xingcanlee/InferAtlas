## Decisions / deviations from contracts

- Release defaults remain **A2/H100**. Qwen does not build cleanly on every Ascend
  device; expanding the default would add unresolved 310P/A3/A5 cells.
- No goldens regenerated: no intentional numeric, annotation or IR changes for
  the four supported cells. No schema, contract, catalog or dependency-lock changes.
- Ascend annotations retain `reviewed_by: pending`. A3's identical meta parameter
  shapes do not establish its runtime behavior; A2 predicates were not widened.
- Unknown dtype peaks mean unknown rooflines, not proof that a dtype is supported
  or unsupported. No bf16 capability was inferred from null 310P/A3 peak fields;
  310P remains blocked on the actually observed implementation gaps.
- A5's numeric release prerequisite is checked by the CLI; the lower-level raw
  extraction API remains available for inspecting meta/profile facts.
- Hosted collection keeps the existing rule that any triaged device blocks the
  whole model from publication. Thus all three models are blocked in the full
  matrix, even though the local review release has four usable exports.

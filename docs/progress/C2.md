# C2-fix — source identity, hardware triage and cell publication

## Done

- Read `docs/design.md`, `docs/dev-plan.md` and the verified CPU/meta experiment.
- Pins now require both full lowercase SHAs. Main pairing reads
  `.github/vllm-main-verified.commit` at the pinned Ascend revision (fetching it
  when absent locally) and requires exactly the vLLM pin. Tagged catalog pairs
  reject pin overrides. CLI identity checks validate tags independently of pins.
- Replaced the synthetic A5 extraction exception with additive
  `hardware_profile_incomplete` triage in the lowerer, preserving all other
  extraction/lowering/annotation diagnostics. Unknown capacity has an explicit
  zero sentinel and never falls back to 64 GB. Direct `lower()` calls share the
  gate; numeric checks and layout skip for any blocking triage. Standalone
  `extract` retains facts and explains the numeric publication prerequisite.
- Regenerated JSON Schema and TypeScript contracts from Pydantic. Web typechecks;
  it has no exhaustive triage-kind switch requiring a label change.
- Collection gates model×device cells. H100 baseline triage also blocks that
  model's Ascend cells; any missing/error cell prevents the whole publication.
  Sorted `blocked_cells` are recorded in summary and publication state, with
  aggregate `models_with_blocked_cells` retained for maintenance retries.
- Removed the unreachable build-exit branch. CPU extraction pins
  `setuptools-scm==10.3.4`. A shallow, tagless clone yields an SCM placeholder
  such as `0.1.dev1`, used only for Ascend import compatibility; it is not a
  release label or a source identity. Main sources keep main labels.
- Regression tests cover pinned release-label rejection, pairing-file mismatch,
  pinned-tree reads/fetches, A5 direct lowering and retained unannotated overrides,
  standalone extraction messages, mixed clean A2/H100 beside triaged 310P,
  H100 dependency gating, missing/error publication failure and state retention.

## How to run

Follow `docs/release.md`: use the shared CPU interpreter/clones, set both validated
pins, build the TS packages, then run `inferatlas release --devices 310P A2 A3 A5
H100 --out dist`. Stage triage-only blocked cells and run `inferatlas site
--include-blocked` into `web/dist`. Both commands intentionally exit 2 after
rendering four clean exports and eleven triaged cells. Artifacts in `dist/` and
`web/dist/` stay uncommitted. Checks: `just lint && just test`,
`uv run --project generator pytest .github/actions/tests`,
`node --test .github/actions/tests/*.test.cjs`, and web `tsc --noEmit`.
